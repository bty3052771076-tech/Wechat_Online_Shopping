## 一、前端数据格式不匹配

### 14. [P1] 优惠券详情页类型字段格式错误

**现状**:
- `pages/coupon/coupon-activity-goods/index.js` L27-35: 用数字判断优惠券类型 (`detail.type === 2`, `detail.type === 1`)
- `pages/coupon/coupon-detail/index.js` 同样问题
- `services/coupon/index.js` 的 `fetchCouponDetail()` 调用 `/api/coupons`，后者返回 `type: 'price'` 或 `type: 'discount'`（字符串）
- 数字判断永远 `false`，优惠券类型描述文字（"满X元减X元"/"满X元X折"）永远不渲染

**根因**: 页面沿用了 mock 数据中的数字型 `type`（1=满减/2=折扣），未同步到 API 字符串约定。

**影响**: 优惠券详情页类型描述永远显示为空，用户无法看到优惠券说明。

**修复范围**:
- `Wechat_Online_Shopping/pages/coupon/coupon-activity-goods/index.js` — 将 `type === 2` 改为 `type === 'discount'`，`type === 1` 改为 `type === 'price'`
- `Wechat_Online_Shopping/pages/coupon/coupon-detail/index.js` — 同上

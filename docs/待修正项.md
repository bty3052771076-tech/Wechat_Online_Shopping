### 1. [P0] 优惠券/促销系统未实现

**需求**: 订单确认页支持选择优惠券, 优惠金额参与结算

**现状**:
- 数据库已定义 `coupons` + `user_coupons` 表 (`database/sql/01-create-tables.sql` L612-672)

**修复范围**:

### 3. [P0] 商品生产日期/保质期字段断链

**需求**: 管理员填写商品的生产日期、保质期; 消费者可查看

**现状**:
- 前端管理端表单正确采集 `productionDate` / `shelfLife` (admin goods-manage edit 页面)
- 前端适配器将字段嵌入 `productDetail` JSON 发送 (`services/_utils/admin-adapters.js` L152-156)
- 后端 controller 接收 `productDetail` 但 **不提取** `production_date` / `shelf_life` 到独立列 (`backend/src/controllers/admin-product.controller.js` L145-226 createProduct, L228-338 updateProduct)
- 数据库 `product_spus` 表有 `production_date` DATE 列和 `shelf_life` INT 列, 但始终为 NULL
- Sequelize 模型 `ProductSpus.js` L86-97 已定义这两个字段
- 消费者商品详情页 (`pages/goods/details/`) 不展示生产日期和保质期

**影响**: 管理员设置的生产日期和保质期数据丢失; 消费者看不到食品安全关键信息

**修复范围**:
- `backend/src/controllers/admin-product.controller.js` — createProduct/updateProduct 提取并存储字段
- `Wechat_Online_Shopping/pages/goods/details/index.wxml` + `index.js` — 展示生产日期和保质期
- `Wechat_Online_Shopping/services/good/fetchGood.js` — 返回数据中包含这两个字段

## 三、配送费校验缺失
